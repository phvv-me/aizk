# Icon Composer source

These four transparent 1024 pixel layers come from the same procedural Blender scene as the AIZK
hero render. Import them from back to front in filename order.

Keep each image in its own group. Use Icon Composer for the background gradient, Liquid Glass,
specular highlights, refraction, translucency, blur, shadow, and platform variants. Do not add a
rounded-square mask because Apple applies the final enclosure.

Suggested starting treatment

- Give the base group low translucency and moderate specular response.
- Give both fold groups more depth than the base and slightly different refraction.
- Keep the source node nearly opaque with the lowest blur.
- Check default, dark, and mono appearances at the smallest preview size before export.
