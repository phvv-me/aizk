This page configures itself for the AIZK deployment serving it. You do not need an API key or a
client secret. Choose your agent, install the AIZK plugin and complete browser sign in.

```text
  1  choose      pick Claude Code or Codex
                        │
  2  install     add the AIZK plugin
                        │
  3  sign in     connect your own AIZK account
                        │
  4  verify      call status, then keep and find one note
```

## 1. Choose your agent

<SetupChooser />

The plugin contains the AIZK skill and the MCP connection together. It does not remove an existing
server or replace project instructions. OpenCode remains available through its manual setup page.

## 2. Complete sign-in

Claude Code asks you to approve AIZK after it opens. Use `/mcp`, select AIZK and choose sign in.
Codex opens sign in from the second command in its panel. Sign in if you already have an account,
or choose account creation and complete email verification if you do not.

When the browser flow finishes, ask the agent to call `status`. A successful response returns your
identity and the organizations you can use. It also confirms the five tools named `status`, `find`,
`keep`, `report` and `share` are ready.

If the browser never comes back, or the client says it is signed out, use
[Sign-in troubleshooting](/docs/user/clients/troubleshooting/).

## 3. Store your first memory

Tell your agent something worth keeping. The agent calls `keep` with self-contained Markdown, and
the first level-one heading becomes the title that `find` shows later.

```python
aizk.keep(
    text="""# Retrieval reranker choice

We kept the cross-encoder reranker on by default. Turning it off saved 40 ms and cost more in
answer quality than the latency was worth."""
)
```

No organization is named, so the note stays private. Dates, tags and sharing remain empty unless
you provide them. [Writing memory well](/docs/user/using/keep/) explains the choices once you
have a few notes.

## 4. Ask for it back

```python
aizk.find(query="why is the reranker on by default?")
```

AIZK returns evidence rather than a finished answer. Your agent reads the relevant source excerpt,
checks where it came from and answers in its own words. [Evidence and
provenance](/docs/user/concepts/evidence/) explains the labels on every result.

:::tip[Good habit]
Write fewer and better notes, then ask one focused question at a time.
:::
